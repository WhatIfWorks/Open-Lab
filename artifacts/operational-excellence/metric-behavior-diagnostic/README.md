# Metric Behavior Diagnostic

## Purpose

Examine what a metric measures, what behavior it encourages, and whether improvement in the number actually represents improvement in the system.

## Intended Audience

Quality, Continuous Improvement, Operational Excellence, operations, and leadership practitioners who design, review, interpret, or act on metrics.

## When to Use It

Use it when reviewing an existing metric, investigating an improving number without a clear system improvement, or examining incentives, trade-offs, and the decisions a metric supports.

## How to Use It

1. Identify the metric and how it is calculated, including inclusions, exclusions, and transformations.
2. Examine Intent, Measure, Incentive, Response, Trade-Off, and Gaming; record observations and evidence.
3. Use Signal to distinguish what movement supports from what it does not establish. Use Decision to identify who should act and what the metric should inform.
4. Trace Metric → Signal → Behavior → Outcome. Ask what a significant improvement in the metric would actually tell you.

## Expected Outputs

- A description of the metric, its calculation, intent, incentives, and observed responses.
- Evidence about trade-offs and ways the number could improve without improving the system.
- Explicit supported inferences, unknowns, and decisions the metric can inform.
- A Metric → Signal → Behavior → Outcome trace.

## Limitations

This is not a KPI scorecard, metric-selection formula, dashboard standard, or grading system. Movement in a metric does not by itself establish improvement in the system. Gaming need not reflect malicious intent. Use evidence and professional judgment; the worksheet does not produce a score or a validated conclusion.
